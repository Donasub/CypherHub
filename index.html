How it works

Three tricks,
one cipher

01

Three faces of the same letter

Every character has three representations: binary (01100001), decimal (97), and itself (a). Same meaning, different costumes. Zigzag picks which one to show at each position.

02

A bouncing pattern picks the costume

Each position is assigned a format: B binary → D decimal → C char → C → D → B and repeats every six positions.

03

A shared keyword shifts everything

Before formatting, each letter is shifted along the alphabet using the keyword a Vigenère cipher. The keyword cycles across the message. Without it, you only recover shifted gibberish.

04

Decoding reverses the steps

Parse each token back to a character using the expected format, then subtract the keyword's shift for that position. You're back to the original plaintext.

The format pattern, visualised (first 12 positions)
B binary 8-bit ASCII D decimal ASCII code C character as-is
⚠ Puzzle-grade, not bank-grade. Short keys are vulnerable to Kasiski analysis once the keyword length is found, the shift collapses to Caesar ciphers crackable by letter frequency. Use Zigzag for notes, puzzles, and trivia. Use it to protect anything that matters from chats to secret conversations etc.
