How it works

Three tricks,
one cipher

01

Three faces of the same letter

Every character has three valid representations: binary (01100001), decimal (97), and itself (a). Same meaning, different costumes. Zigzag picks which one to show at each position in the message.

02

A bouncing pattern picks the costume

Each position is assigned a format: B binary → D decimal → C char → C → D → B — then repeats. The pattern zigzags up and down across the message, giving the cipher its name.

03

A shared keyword shifts everything

Before formatting, each letter is shifted along the alphabet by an amount set by the keyword a Vigenère cipher. The keyword cycles across the message. Without the keyword, you only recover shifted gibberish, not the real message.

04

Decoding reverses the steps

Parse each token back to a character using the expected format at that position, then subtract the keyword's shift. You're back to the original plaintext. You and your friend just need to share the keyword somehow that's the only secret.

⚠ Puzzle-grade, not bank-grade. Short keys are vulnerable to Kasiski analysis once the keyword length is found, the shift collapses to simple Caesar ciphers crackable by letter frequency. True security requires a key as long as the message, never reused. Use Zigzag for notes, puzzles, and trivia. Use it to protect anything that matters from chats to secret conversations etc.
