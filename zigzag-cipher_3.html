Zigzag

v1 · client-side only

A small cipher for shared secrets. Type a message, pick a keyword, hand the result to a friend who also knows the word.

Two pieces stack: a letter shift by your keyword (Vigenère), then a bouncing rotation through three formats — binary, decimal, character. Everything runs in this tab. Nothing leaves your device.

How this works

Three faces of the same letter

Every letter has three valid representations: its binary code (01100001), its decimal code (97), and itself (a). All three mean the same thing — they're just wearing different costumes.

A bouncing pattern decides which costume

The cipher rotates through binary → decimal → character, then bounces back: character → decimal → binary. The pattern repeats every six positions. Whichever costume shows up depends only on the letter's position in the message, not on the letter itself.

A shared keyword shifts everything underneath

Before formatting, each letter is bumped forward in the alphabet by an amount set by the keyword (a Vigenère shift). The keyword cycles too — wave applied to a 12-letter message reuses w, a, v, e, w, a, v, e, w, a, v, e. Without the keyword, a snooper sees the format pattern but only recovers shifted gibberish, not your real message.

Decoding runs the same steps in reverse

Read each token in its expected format to get a letter, then subtract the keyword's shift for that position. You're back to the original.

About the security. This is puzzle-grade, not bank-grade. Short keys are vulnerable to Kasiski analysis — once your keyword length is found, the shift collapses to a series of Caesar ciphers you can crack with letter frequency. True one-time-pad strength requires a key as long as the message and never reused. Real cryptography also solves the key-distribution problem this app sidesteps: you and your friend have to share the keyword somehow. Use Zigzag for notes, puzzles, and trivia. Don't use it to protect anything that matters.
